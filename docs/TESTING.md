# Руководство по тестированию Auction Simulator

Это руководство описывает пошаговый процесс тестирования приложения Auction Simulator через Telegram Mini App.

## Предварительные требования

1. **Запущенное приложение**
   - Backend должен быть запущен и доступен
   - Frontend должен быть запущен и доступен
   - MongoDB и Redis должны быть запущены

2. **Telegram Bot**
   - Telegram бот `@auction_simulator_bot` должен быть настроен и активен
   - Webhook должен быть настроен для получения обновлений

3. **Доступ к Telegram**
   - Аккаунт Telegram для тестирования
   - Возможность открыть Mini App через бота

## Пошаговое тестирование

### Шаг 1: Откройте приложение через Telegram бота

1. Откройте Telegram
2. Найдите бота `@auction_simulator_bot`
3. Отправьте команду `/start` боту
4. Бот должен ответить приветственным сообщением
5. Нажмите на кнопку для открытия Mini App (или используйте ссылку из бота)

**Ожидаемый результат:**
- Бот отвечает на команды
- Mini App открывается в Telegram
- Приложение загружается и показывает страницу аутентификации/приветствия

---

### Шаг 2: Измените роль на admin

1. В чате с ботом отправьте команду `/role`
2. Бот должен изменить вашу роль на `admin`

**Ожидаемый результат:**
- Бот подтверждает изменение роли
- Ваш аккаунт получает права администратора
- В приложении появляется доступ к админ-панели

**Примечание:** Если команда `/role` не работает, проверьте:
- Настроен ли Telegram Bot Token в переменных окружения
- Активен ли webhook для бота
- Правильно ли обрабатываются команды в `telegramBotService`

---

### Шаг 3: Откройте Mini App и войдите в админ-панель

1. Откройте Mini App через бота (если еще не открыто)
2. Дождитесь завершения аутентификации
3. После успешной аутентификации вы должны увидеть главную страницу
4. Найдите и откройте раздел "Admin Panel" или "Админ-панель"

**Ожидаемый результат:**
- Аутентификация проходит успешно
- Отображается главная страница приложения
- Доступна кнопка/ссылка для входа в админ-панель
- В админ-панели доступны функции управления

---

### Шаг 4: Измените баланс

1. В админ-панели найдите раздел "Wallets" или "Кошельки"
2. Найдите свой кошелек (по вашему Telegram User ID)
3. Нажмите на кошелек для редактирования
4. Введите новую сумму баланса
5. Сохраните изменения

**Ожидаемый результат:**
- Кошелек найден и отображается
- Баланс успешно обновлен
- Новый баланс отображается в интерфейсе
- Изменения сохраняются в базе данных

**Проверка:**
- Обновите страницу - баланс должен остаться измененным
- Проверьте через API: `GET /wallets/{your_user_id}`

---

### Шаг 5: Создайте коллекцию подарков

1. В админ-панели перейдите в раздел "Collections" или "Коллекции"
2. Нажмите кнопку "Create Collection" или "Создать коллекцию"
3. Заполните форму:
   - Название коллекции
   - Описание (опционально)
   - Количество подарков в коллекции
4. Сохраните коллекцию

**Ожидаемый результат:**
- Коллекция успешно создана
- Коллекция появляется в списке коллекций
- Можно перейти к созданию подарков для этой коллекции

**Следующие шаги (опционально):**
- Создайте подарки для коллекции через раздел "Gifts"
- Убедитесь, что подарки привязаны к созданной коллекции

---

### Шаг 6: Создайте аукцион

1. В админ-панели перейдите в раздел "Auctions" или "Аукционы"
2. Нажмите кнопку "Create Auction" или "Создать аукцион"
3. Заполните форму создания аукциона:
   - Выберите коллекцию (созданную на шаге 5)
   - Укажите длительность раунда (в секундах)
   - Укажите количество подарков на раунд
4. Нажмите "Create" или "Создать"

**Ожидаемый результат:**
- Аукцион успешно создан
- Аукцион автоматически запускается (статус меняется на "active")
- Аукцион появляется в списке активных аукционов
- Создается первый раунд аукциона

**Проверка:**
- Аукцион должен быть виден на странице "Auctions"
- Статус аукциона должен быть "active"
- Должен быть создан первый раунд

---

### Шаг 7: Перейдите на страницу аукционов и откройте аукцион

1. В главном меню приложения перейдите в раздел "Auctions" или "Аукционы"
2. Найдите созданный аукцион в списке
3. Нажмите на аукцион для просмотра деталей

**Ожидаемый результат:**
- Список аукционов отображается корректно
- Созданный аукцион виден в списке
- При открытии аукциона отображается:
  - Информация об аукционе (коллекция, длительность раунда)
  - Текущий раунд
  - Таймер до окончания раунда
  - Список ставок (если есть)
  - Кнопка для размещения ставки

---

### Шаг 8: Создайте ставки и проверьте раунды

#### 8.1. Размещение ставки

1. На странице аукциона найдите форму для размещения ставки
2. Введите сумму ставки (не превышающую ваш баланс)
3. Нажмите "Place Bid" или "Разместить ставку"

**Ожидаемый результат:**
- Ставка успешно размещена
- Средства замораживаются (frozen_balance увеличивается, available_balance уменьшается)
- Ставка появляется в списке ставок
- Обновление происходит в реальном времени через WebSocket

#### 8.2. Проверка раундов

1. Дождитесь окончания текущего раунда (или используйте короткую длительность для тестирования)
2. Наблюдайте за процессом settlement (завершения раунда)

**Ожидаемый результат:**
- По истечении времени раунд автоматически завершается
- Определяются победители (топ-N по сумме ставки)
- Средства победителей списываются
- Средства проигравших размораживаются
- Подарки распределяются победителям
- Создается следующий раунд (если есть непроданные подарки)

#### 8.3. Проверка следующего раунда

1. После завершения раунда проверьте, что создан новый раунд
2. Убедитесь, что ваша ставка скопирована в новый раунд
3. Проверьте, что таймер нового раунда запущен

**Ожидаемый результат:**
- Новый раунд создан и активен
- Ставки из предыдущего раунда скопированы
- Таймер нового раунда работает корректно
- Можно размещать новые ставки (если еще не размещали)

---

### Шаг 9: Проверьте профиль и инвентарь после завершения

1. Дождитесь завершения всех раундов аукциона
2. Перейдите в раздел "Profile" или "Профиль"
3. Откройте раздел "Inventory" или "Инвентарь"

**Ожидаемый результат:**
- Если вы выиграли подарок в одном из раундов:
  - Подарок отображается в инвентаре
  - Подарок привязан к вашей учетной записи
  - Информация о подарке корректна (название, описание, коллекция)
- Если вы не выиграли:
  - Инвентарь пуст или содержит только ранее полученные подарки
  - Средства разморожены и возвращены на баланс

**Проверка через API:**
- `GET /ownerships?user_id={your_user_id}` - должен вернуть список ваших подарков
- `GET /wallets/{your_user_id}` - проверьте финальный баланс

## Дополнительные проверки

### Проверка WebSocket обновлений

1. Откройте приложение в нескольких вкладках/устройствах
2. Разместите ставку в одном окне
3. Убедитесь, что обновление отображается во всех окнах в реальном времени

**Ожидаемые события:**
- `bid_placed` - при размещении ставки
- `round_started` - при начале нового раунда
- `round_settled` - при завершении раунда
- `auction_finished` - при завершении аукциона

### Проверка Anti-sniping защиты

1. Разместите ставку в последние 10 секунд раунда
2. Попытка должна быть отклонена

**Ожидаемый результат:**
- Ставка отклонена с сообщением о блокировке в последние 10 секунд
- Сообщение указывает оставшееся время до окончания раунда

### Проверка одной ставки на пользователя

1. Разместите ставку в аукционе
2. Попробуйте разместить вторую ставку в том же аукционе

**Ожидаемый результат:**
- Вторая ставка отклонена
- Сообщение об ошибке: "User has already placed a bid in this auction"

### Проверка баланса и заморозки средств

1. Разместите ставку на сумму X
2. Проверьте баланс кошелька

**Ожидаемый результат:**
- `available_balance` уменьшился на X
- `frozen_balance` увеличился на X
- `total_balance` остался неизменным

## Тестирование в Mock Mode

Если вы тестируете приложение в режиме разработки с `VITE_MOCK_TELEGRAM=true`:

1. **Аутентификация:**
   - Приложение использует mock данные Telegram
   - Не требуется реальный Telegram аккаунт
   - Mock данные автоматически инициализируются

2. **Ограничения Mock Mode:**
   - Некоторые функции Telegram Mini App могут быть недоступны
   - WebSocket может работать по-другому
   - Некоторые UI элементы могут отличаться

3. **Рекомендации:**
   - Для полного тестирования используйте реальный Telegram Mini App
   - Mock mode подходит для разработки и базового тестирования функциональности

## Устранение неполадок

### Проблема: Бот не отвечает на команды

**Решения:**
1. Проверьте, что `TELEGRAM_BOT_TOKEN` установлен в переменных окружения
2. Убедитесь, что webhook настроен: `POST /telegram-bot/webhook`
3. Проверьте логи backend на наличие ошибок
4. Убедитесь, что бот активен в Telegram

### Проблема: Mini App не открывается

**Решения:**
1. Проверьте, что frontend запущен и доступен
2. Убедитесь, что `TELEGRAM_MINI_APP_URL` настроен правильно
3. Проверьте CORS настройки в backend
4. Откройте консоль браузера для проверки ошибок

### Проблема: Аукцион не создается

**Решения:**
1. Убедитесь, что у вас есть права admin (команда `/role`)
2. Проверьте, что коллекция создана и содержит подарки
3. Проверьте логи backend на наличие ошибок валидации
4. Убедитесь, что MongoDB и Redis работают

### Проблема: Ставки не размещаются

**Решения:**
1. Проверьте баланс кошелька (должен быть достаточным)
2. Убедитесь, что раунд активен (не в процессе settlement)
3. Проверьте, что не истекло время раунда
4. Убедитесь, что вы еще не размещали ставку в этом аукционе
5. Проверьте, что не действует anti-sniping защита (последние 10 секунд)

### Проблема: Раунды не завершаются автоматически

**Решения:**
1. Проверьте, что Redis работает и доступен
2. Убедитесь, что таймеры раундов настроены в Redis
3. Проверьте логи backend на наличие ошибок в `RoundTimerService`
4. Убедитесь, что `RecoveryService` запускается при старте сервера

### Проблема: Подарки не появляются в инвентаре

**Решения:**
1. Убедитесь, что вы были в топ-N победителей раунда
2. Проверьте, что settlement выполнился успешно
3. Проверьте через API: `GET /ownerships?user_id={your_user_id}`
4. Обновите страницу инвентаря
5. Проверьте логи backend на наличие ошибок в `SettlementService`

## Проверка через API

Для дополнительной проверки можно использовать API endpoints:

```bash
# Проверить пользователя
curl http://localhost:8080/users/{user_id}

# Проверить кошелек
curl http://localhost:8080/wallets/{user_id}

# Проверить аукционы
curl http://localhost:8080/auctions

# Проверить ставки раунда
curl "http://localhost:8080/bids?auction_id={auction_id}&round_number={round_number}"

# Проверить собственность (подарки)
curl "http://localhost:8080/ownerships?user_id={user_id}"
```

После прохождения всех шагов вы должны убедиться, что:

- ✅ Аутентификация работает корректно
- ✅ Админ-панель доступна и функциональна
- ✅ Аукционы создаются и запускаются
- ✅ Ставки размещаются и обрабатываются
- ✅ Раунды завершаются автоматически
- ✅ Победители определяются правильно
- ✅ Подарки распределяются и отображаются в инвентаре
- ✅ WebSocket обновления работают в реальном времени
- ✅ Балансы обновляются корректно

Если все шаги выполнены успешно, приложение работает корректно и готово к использованию.
